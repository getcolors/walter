GREEN PACKAGE SKILL

walter

Provision and operate one remote development machine, maintain its SSH alias, and power supported OCI machines off and on when they are not in use.

npx skills add getcolors/walter
cp .agents/skills/package-walter-green/walter walter
./walter build
./walter create --dry-run
./walter stop
./walter start

Desired state is colors.yml; credentials arrive only through COLORS_PAR_*. Real create and delete operations require explicit care.
